# Displyfy Asset Library

Store approved page media in this directory. Files under `public/assets/` are served from `/assets/`; for example, `public/assets/editorial/tech-creator-laptop-sticker.webp` is referenced as `/assets/editorial/tech-creator-laptop-sticker.webp`.

Keep source prompts and temporary exports outside the repository. Use optimized WebP or AVIF deliverables, descriptive kebab-case filenames, and meaningful alt text at each point of use. Do not add third-party logos, embedded text, or unlicensed stock media.
