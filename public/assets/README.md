# Displyfy Asset Library

Store generated illustrations and other page media in this directory. Files under `public/assets/` are served from `/assets/`; for example, `public/assets/illustrations/creator-editing.webp` is referenced as `/assets/illustrations/creator-editing.webp`.

Keep source prompts and temporary exports outside the repository. Commit optimized WebP or AVIF deliverables, use descriptive kebab-case filenames, and provide meaningful alt text at each point of use. Do not add third-party logos, embedded text, or unlicensed stock media.
